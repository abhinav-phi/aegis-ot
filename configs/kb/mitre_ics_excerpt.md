# MITRE ATT&CK for ICS (excerpt)

T0862 Supply Pump Compromise: adversary manipulates supply pumps to affect
process state. T0846 Process Manipulation: adversary changes process control
values to alter physical outcomes. T0875 Unauthorized Command Message:
adversary sends unauthorized commands to control devices. T0838 Unauthorized
Stop: adversary issues stop commands to halt equipment. Detection and response
should cite the technique identifier and evidence basis.
